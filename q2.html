Differences between a Google Doc and an HTML Document

The primary difference between a Google Doc and an HTML document is that HTML relies on a markup language code, not easily learned for new users unfamiliar with code. Whereas Google Docs are newcomer-friendly, catered for newer users or users who don't know code. Additionally, they are both completely different file types, although both may show text, styles, links, images, and more; Google Docs is contained in the cloud, saved as a g.doc, while HTML is a text code file typically saved as .html.

There are various differences between the two, consisting of their purpose: Docs being for text documents, reports, etc., while HTML is for web content, pages, etc. Additionally, collaboration differs drastically. Docs display real-time collaboration; HTML doesn't have that. These are simply a few differences.
